# UI mobile-first, i18n FR, déploiement GitHub Pages

Navigation par onglets bas sur mobile (Accueil favoris · Recherche · Profils · Réglages), barre haute sur desktop, fiche item empilée. Interface en français par défaut avec couche de traduction dès le départ (i18n prête au changement de langue).

Déploiement sur GitHub Pages : HTTPS garanti pour la PWA, contraintes de base path gérées avec vite-plugin-pwa.
