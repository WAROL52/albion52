# Périmètre MVP et coutures de modules

Vision E (dashboard tout-en-un), mais MVP = rentabilité du craft, seul. Chaque module futur (gathering, merchant, ledger) sera un écran branché sur le fond commun déjà bâti : profils, marchés, prix AODP, cache, persistance.

Hors MVP, explicitement : écran « top crafts », or/€, historique des prix, langues hors FR/EN, distribution des qualités. Ordre post-MVP : classement (prolonge le socle, exige IndexedDB) → or/€ + historique → selon pratiques (merchant / gathering / ledger).
